## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Default pytest temp dir | pytest errors with PermissionError on `C:\Users\OMack\AppData\Local\Temp\pytest-of-OMack` in agent sessions; shows as a test ERROR, not a code fault | advisory | Always run with `-p no:cacheprovider --basetemp=.pytest-temp/<name>` (local, untracked) |
| Shell heredoc edits | A heredoc escape wrote a NUL byte into a Python script during 06-02 | advisory | Edit files with Edit/Write tools, not shell heredocs |
| Plans assuming green between commits | Publisher manifest pinned the live script digest and the reply builder validated the committed sign-off, so any publisher edit turned real-file tests red before republication | advisory | When planning publisher edits, list the real-file tests that go red until the next publication commit; never add skips or shims |
| Staging unrelated work | Working tree carries unrelated modifications | advisory | Stage by explicit path only; never `git add -A`/`.`, stash or reset |
