## Shared Patterns

### Fail closed with a domain error
**Source:** publisher lines 45, 417-434. `class AuthorityError(ValueError): pass`; every violated invariant raises; CLI prints `PASS` or dies non-zero.
**Apply to:** the reply script and its `validate`.

### Deterministic LF output and digests
**Source:** publisher lines 47-53, 322-327: `lf_digest`, `lf_bytes`, `dump`, `jtext`, `write_text`.
**Apply to:** all three generated files; compare using `lf_bytes(on-disk) == text.encode('utf-8')` so a CRLF checkout still validates.

### No absolute paths in registry JSON
**Source:** publisher `contains_absolute` (lines 54-58). Store repo-relative forward-slash paths (e.g. `registry/archive_assessment_applicability_authority_v2.json`, `generated/archive-assessment/ems-aa3-v2/archive_assessment_applicability_authority_v2_decision_traceability.json`). Take the file names from `V2.N_TRACE`, `V2.N_MANIFEST`, `V2.rel(V2.AUTHORITY)`, not typed.

### Published-file protection (D-17/D-18)
The manifest binds the publisher script's digest. `python scripts/publish_archive_assessment_applicability_authority_v2.py --validate` must print `PASS` before and after Phase 5. Do not edit that script, the v2 schema, the v2 authority, sign-off, record, or anything in `generated/archive-assessment/ems-aa3-v2/`. Stage by explicit path; never `git add -A`. The working tree holds unrelated modified `registry/adjudication_rules.json`, `registry/policy_decisions.json`, `schemas/archive_assessment_governance_answers.schema.json` and many untracked files; leave them out of the commit.

### Commit split (Phase 4 D-20 precedent)
Commit 1: script + schema + test + `.gitattributes`. Commit 2: generated `docs/` and `registry/` reply files after running `--build` (so the generated files are in a commit after the code). End commit messages with the attribution line given in the session.

### Pytest run on Windows
`tmp_path` fails here; use the module-level `TemporaryDirectory` fixture or `--basetemp=<writable dir>`. Do not leave `.pytest-*` dirs staged.
