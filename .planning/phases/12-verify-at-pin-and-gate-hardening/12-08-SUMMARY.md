# Phase 12 Plan 08: At-pin binds the pinned tree to HEAD (CR-01 gap closure) Summary

At-pin PASS now means the bytes it validated are the pinned commit's bytes. `--validate --at-pin` compares each of the 11 pinned paths, LF-normalised, with `git cat-file blob HEAD:<path>`, rejects any index tag other than `H`, and then runs a hardened `git status` that also shows ignored and untracked files in the output folder. Plain `--validate` binds the 10 D-05 files on disk to HEAD with the same function. Real-git tests in this repository's layout show that the pre-fix status was silent for each blind spot and that the new check fails closed. The red set stayed at the D-16 end state at every commit.

## What was done

**Task 1 — publisher fix and adapted tests (d7a98f7, ledger b0c1796)**
- `git_run`: the OSError message names the first non-option argument (`git status:`, not `git --literal-pathspecs:`).
- `git_dirty`: argv is now `--literal-pathspecs status --porcelain --untracked-files=all --ignored=matching -- <paths>`.
- New `git_commit_blob(commit, path)`: reads blob bytes via `git cat-file blob`. It validates the SHA and path before calling git and raises GitHistoryError on rc != 0.
- New `git_index_flags(paths)`: reads `git ls-files -v` and reports every path that is not in the index or has a tag other than `H`.
- New `check_tree_matches_head(paths)`: checks each path in order (committed at HEAD, present on disk, LF bytes equal), then checks the index flags.
- At-pin wiring: `git_not_shallow` → `check_tree_matches_head([*publication_paths(), rel(SCRIPT)])` → `git_dirty([..., rel(SCRIPT), rel(OUT)])`. The new message is `at-pin: git status (untracked and ignored files shown) ...`, and the phrase "modified or untracked" is gone.
- Plain wiring: `check_tree_matches_head(publication_paths())` is the last plain-mode check, after the pinned-script digest.
- Tests: `REAL_CHECK_TREE_MATCHES_HEAD` is captured, faked in `env`, and restored in `use_real_git_state` and the existing at-pin real-git test. Assertions were updated for the new argv, call lists (11 paths and 12 paths) and messages.

The publisher keeps CRLF only (0 bare LF), and the test file keeps LF only (0 CRLF).
