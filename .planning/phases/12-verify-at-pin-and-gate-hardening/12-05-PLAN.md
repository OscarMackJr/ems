- git_head() -> str — `rev-parse HEAD`, returns a 40-hex SHA or raises GitHistoryError
- git_is_ancestor(ancestor: str, descendant: str) -> bool — both args 40-hex (else AuthorityError); `merge-base --is-ancestor`; rc 0 True, rc 1 False, other rc GitHistoryError
- git_not_shallow() -> None — `rev-parse --is-shallow-repository`; passes only on exactly 'false'; 'true' → GitHistoryError containing 'shallow' and 'fetch full history'; other output → GitHistoryError containing 'cannot tell whether the clone is shallow' and repr of the output
- git_dirty(paths: list[str]) -> list[str] — each path checked with bad_rel; `status --porcelain -- <paths>`; returns the non-empty output lines; non-zero rc → GitHistoryError
- publication_paths() -> list[str] — the 10 D-05 paths, order [rel(AUTHORITY), rel(SCHEMA), rel(SIGNOFF)] + [f'{rel(OUT)}/{n}' for n in (N_MATRIX, N_SEMANTIC, N_NEGATIVE, N_TRACE, N_CERT, N_REPORT, N_MANIFEST)]
- AT_PIN_DEFERRED: str constant, starts with 'PUBLICATION_RECORD_BINDING: '
- validate_published(at_pin: bool = False) -> None; check_publication_record(a: dict, at_pin: bool = False) -> None

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| verifier's working tree to publisher | at the pin, working-tree bytes are what gets validated; they may differ from the pinned commit |
| git CLI output to publisher | rc/stdout of status, rev-parse, merge-base decide trust |
| record file to at-pin check | record names which publication is superseded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-05-01 | Tampering | dirty tree at the pin certifies the wrong bytes | mitigate | git_dirty over the 10 D-05 paths plus the publisher script runs first in at-pin mode; real-repo test edits authority and script |
| T-12-05-02 | Tampering | option/argument injection into git via commit or path | mitigate | 40-hex regex on SHAs and bad_rel on paths before git_run; `--` separators in git_show and git_dirty |
| T-12-05-03 | Repudiation | shallow or unknown clone state yields a false PASS | mitigate | git_not_shallow passes only on exactly 'false'; unknown output shown raw; GitHistoryError otherwise |
| T-12-05-04 | Spoofing | at-pin record names an arbitrary earlier publication | mitigate | Record must equal source_lineage.supersedes (itself pinned to the constant by validate_publication) and its digests must match blobs at that commit |
| T-12-05-05 | Repudiation | at-pin PASS read as full verification | mitigate | Output names exactly one deferred check (PUBLICATION_RECORD_BINDING) and where to run it |
| T-12-05-06 | Elevation | new subprocess call sites outside the seam | mitigate | Source-scan tests strip only git_show and git_run and forbid subprocess elsewhere |
| T-12-05-SC | Tampering | package installs | accept | No packages installed |
</threat_model>
