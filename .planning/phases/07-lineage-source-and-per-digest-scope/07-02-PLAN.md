<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authority JSON -> git_show | `commit` and `relative_path` values from a document reach a subprocess argument |
| repo history -> validator | absence of history could be mistaken for success |
| recorded digest -> recompute | a digest could be edited to match a changed file |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05 | Tampering | git_show argument injection | mitigate | `re.fullmatch('[0-9a-f]{40}')` on commit, `contains_absolute` and `..` rejection on path, single `rev:path` argument, list-form args, no shell |
| T-07-06 | Repudiation/Tampering | fail-open on missing/shallow history | mitigate | every OSError/non-zero git exit raises AuthorityError; missing file raises; no skip branch (D-11) |
| T-07-07 | Tampering | digest or normalisation edited to fit | mitigate | validate_lineage recomputes and compares; declared normalisation must equal EXPECTED_NORMALISATION; schema const pins path and normalisation (D-04) |
| T-07-08 | Elevation of Privilege | subprocess surface growth | mitigate | subprocess confined to git_show; narrowed test asserts it appears nowhere else |
| T-07-09 | Denial of Service | IO in mutation harness | mitigate | validate_lineage only in validate_published, not in validate_publication |
| T-07-SC | Tampering | package installs | accept | no new dependencies |
</threat_model>
