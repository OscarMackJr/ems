# EMS-CTRL-011 — CODEOWNERS Enforcement

Objective: governed repositories have explicit engineering ownership and required Code Owner review for protected branches.

Assertions:
1. CODEOWNERS exists in a supported location.
2. Default ownership identifies an authorized OscarMackJr organization team.
3. The default branch requires pull requests.
4. Code Owner review is required.
5. Exceptions follow the EMS exception process.

Evaluation:
- PASS: all assertions are evidenced.
- WARNING: CODEOWNERS exists but enforcement is incomplete or cannot be established.
- FAIL: CODEOWNERS is absent or a required assertion is demonstrably disabled.
- NOT_EVALUATED: permissions/capability prevent reliable evaluation.
